# A1 Broker – a1broker.com.ar

Sitio estático publicado con Cloudflare Pages (igual que grupoac-web). El código fuente está en la carpeta del proyecto (a1-broker-web-corregida.zip).

## Publicación

Cada push a `main` publica solo en Cloudflare Pages (proyecto `a1broker-web`, cuenta info@grupoac.com.ar).
Si deja de publicar: en GitHub > Settings > Applications > Cloudflare Workers and Pages, el repo `a1broker-web` tiene que estar en la lista de repositorios con acceso.
